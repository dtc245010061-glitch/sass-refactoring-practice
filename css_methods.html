Bài tập: Nhúng CSS vào trang HTML

Phần 1: Inline Style (Tiêu đề màu đỏ)

Đoạn văn này sử dụng inline style trực tiếp trong thẻ với màu tím.

Phần 2: Internal Style (Tiêu đề màu xanh lá)

Đoạn văn này được định dạng bằng thẻ <style> trong phần <head> với màu xanh dương.

Phần 3: External Style (Tiêu đề màu cam đậm)

Đoạn văn này được định dạng thông qua file liên kết bên ngoài (css/external-style.css) với màu xám chì.
