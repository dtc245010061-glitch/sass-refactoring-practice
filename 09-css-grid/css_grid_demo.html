Thực Hành Minh Họa CSS Grid Layout

1. Bố Cục Trang Web Bằng grid-template-areas

HEADER (grid-area: header)
MENU (grid-area: menu)

MAIN CONTENT (grid-area: main)

Sử dụng grid-template-areas giúp việc phân chia các vùng Header, Menu, Main, Sidebar, Footer trở nên trực quan, dễ quản lý và dễ responsive mà không cần dùng float hay tính toán phần trăm margin thủ công.

SIDEBAR (grid-area: sidebar)
FOOTER (grid-area: footer)
